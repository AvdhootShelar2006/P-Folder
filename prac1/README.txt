AI Assignments Practicals (Part A and Part B)

This folder contains all 14 Python practicals from the supplied assignment lists.

Requirements:
- Python 3.9 or later
- No third-party packages are required.

How to run:
1. Open a terminal in this folder.
2. Run the required file with:
   python "filename.py"

Each program requests its required input at runtime. For the Sudoku practical, enter nine rows with nine space-separated numbers per row and use 0 for blank cells.
